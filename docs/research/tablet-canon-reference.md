## Correction Notice

This file was created to correct three errors present in a prior research session (2026-09-26):

1. **Alabaster and Albedo misclassified.** Files `docs/tablets/ALABASTER_TABLET.md` and `docs/tablets/ALBEDO_TABLET.md` exist in the repository but carry **no registry entry** in `docs/tablets/INDEX.md` — no issue number, no element, no stage, no seal status. They are not part of the canonical 18-tablet registry and must not be cited as canon until formally registered.

2. **Sealed/unsealed count inverted.** The correct count is **6 sealed** and **12 unsealed**, not the reverse.

3. **Unsourced stage sequence presented as canon.** A numbered 0–7 alchemical stage sequence (including "Sol Niger" at Stage 5 and "Magnum Opus" at Stage 7) was presented without sourcing from the repository. No such numbered sequence exists in `docs/tablets/INDEX.md`. Only the stage assignments in the table above are canon-sourced. Any extended stage framework must be traced to a specific repository file before being treated as authoritative.
