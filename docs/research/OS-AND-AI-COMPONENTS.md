# OS and AI components

Issues #1514 and #1515. Research pass of 2026-10-02.

Tanenbaum and Bos, Modern Operating Systems, 5th edition: processes, threads, memory, file systems, I/O, deadlocks. Boot is firmware, bootloader, kernel. A driver translates a request. A filesystem maps a path. Virtual memory uses page tables.

NIST AI RMF 1.0: Govern, Map, Measure, Manage. Voluntary. A production stack needs data, a model, orchestration, a guard, an evaluation, observability, integration, a human halt, and a cost record. A superintelligence claim needs a measured task and a baseline. This tree does not have that measurement.
