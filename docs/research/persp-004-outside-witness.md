# What an outside witness would have to be

Issue: #1257. Follows the limit already on main. Leaves #1257 open.

A report, a receipt, and a trace header can be stored. None of them is the witness. An outside witness would have to be a person or a system that did not write the claim, can run the named failure, and can refuse the claim without the catalog agreeing. `EligibleForReview` is not that witness. This note does not appoint one.
