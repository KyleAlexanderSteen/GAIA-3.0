# Universal Magic Ontology

Listed on GAIA 2.0. Magic here is a framework for representing intentional transformation that a source describes as extraordinary, symbolic, metaphysical, ritual, technological, or beyond ordinary operation.

It does not declare that a supernatural mechanism exists.

M0 through M14. A checked load records the counts in the commit. Source status is claimed, observed, modeled, verified, or unknown. Evidence class runs from mythological to verified, plus unknown. No item in this seed is verified.

A named resource is not a physical quantity. Temporal and reality-model rows are constructs unless evidence says otherwise. Unbounded magic is a classification; the bound is unknown. Consciousness-model magic is a model. It is not a claim that SI is conscious.

Representation of magic is not proof of magic.
