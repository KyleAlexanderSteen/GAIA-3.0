# Universal Skills Ontology

Listed on GAIA 2.0. Not an execution engine. A named skill is not a skill GAIA has.

Twenty-six categories, S0 through S25. S0 is meta-skills. Memory is coupled to provenance. Communication is not language knowledge. Novelty is not usefulness. A decision is not a prediction. Knowing is not doing.

Checked load is recorded in the commit. Maturity is 0 unknown through 10 adaptive. No agent on this tree has a level. A level without a verification record is not a level. The example counts in the source note are not seeded.

Social, ethical, and self-management rows do not imply emotion or consciousness. SI physical skill is only an embodiment this system has. None is assumed.

Loop: know, practice, act, observe, evaluate, correct, learn, improve.
