# Universal Capabilities and Powers Ontology

Listed on GAIA 2.0. Works for humans, animals, organizations, AI, SI, machines, biological systems, and hybrids. No agent is seeded as possessing a capability.

A capability is potential action. A power is consequential capacity to produce effects. Potential is not demonstration.

C0 through C19. Sixteen super-capabilities, SC-01 through SC-16, in this file. Eight power families, P1 through P8. This numbering is the UCPO cut. The earlier USPCO file keeps its own codes.

States run from conceptual to generalized. No row is past conceptual. Autonomy does not imply consciousness, personhood, or moral agency. A physical power needs a mechanism.

Constraints sit beside powers: permitted, required, unable, forbidden, authorization, safety, reversibility, evidence. The chain is reversible: an effect must trace to action, power, capability, skill, knowledge, and evidence.
