# Universal Super-Capabilities and Super-Powers

Listed on GAIA 2.0. USCO is SC-00 through SC-20. USPO is SP-01 through SP-15. Earlier UCPO and USPCO files keep their own codes.

A super-capability changes range, composition, adaptability, or coordination. It is not a stronger ordinary skill. A super-power is an effect across scale, range, speed, persistence, complexity, or transformation. It is not supernatural.

Every power in this seed is conceptual. A row without preconditions, mechanism, scope, constraints, and evidence stays conceptual. Autonomy is not consciousness. A forecast keeps uncertainty. Reality-modeling is not reality manipulation. A physical power needs a mechanism. An autonomous power needs an authorization and a boundary.
