# Universal Super Skills Ontology

Listed on GAIA 2.0. A super skill coordinates other skills. It is not a better grade of an ordinary skill, and it is not possessed because it is named.

SS-00 through SS-28. A claimed super skill is not a demonstrated super skill until it has evidence. Status values are potential, claimed, tested, verified, operational. No row in this seed is verified.

An analogy must be tested. A derived skill stays proposed until verified. Foresight keeps assumptions, evidence, uncertainty, and a horizon.
