# docs/canon/

> Proof: PROOF-CANON-GOV-README-001

This directory is the **meta-canon** — the governance layer that defines how
GAIA's Hermetic Tablet Canon is written, sealed, amended, and retired.

The tablets themselves live in docs/tablets/. The proofs live in proofs/.
This directory contains the *rules* that make those artifacts binding.

## Governance Principle

The canon is only as strong as its governance. A tablet sealed without a
witnessed ceremony is informal. A change made without the amendment protocol
is arbitrary. These documents exist so that every future contributor — human
or AI — operates on the same explicitly defined rules.

Machine-readable listed fields live in canon-runtime/README.md.
Presence there is not enforcement.
