`ENTITY → IDENTITY → STATE → RELATION → CAPABILITY → AUTHORITY → AUTHORIZATION → ACTION → EFFECT → EVIDENCE → VERIFICATION → TRANSITION / RECOVERY`

## 7. Continuity-under-transformation test

Primary test:

`PRIOR STATE → TRANSFORMATION / TRANSMUTATION → NEW STATE`

For each transition, ask whether the following remain recoverable:

- identity
- lineage
- provenance
- function
- relation
- meaning
- agency
- memory
- constitutional invariants

Decision rule:

A candidate should not become a universal primitive merely because it is useful, poetic, historically resonant, or broadly applicable. Promotion requires demonstrated irreducibility or material semantic loss when represented using existing primitives.

## 8. Propagation test

Provisional semantic:

> Propagation is the transmission, extension, continuation, or spread of a state, relation, pattern, effect, signal, resource influence, capability expression, or transformation across a defined boundary.

Grammar:

`SOURCE / STATE → RELATION / CHANNEL → PROPAGATION → AFFECTED TARGET(S) → EFFECT → STATE′`

Distinguish propagation from:

- replication
- transmission
- transformation
- cascade
- growth
- diffusion
- influence

Propagation is neutral. Successful propagation does not establish legitimacy, flourishing, truth, or authorization.
