# Fiction survey: symbol systems (inspiration only, not evidence of security)

| System | What it is | Design idea worth borrowing | Source |
|---|---|---|---|
| Wakandan (Black Panther, 2018) | Alphabet designed by Hannah Beachler's team, based on Nsibidi and other real African writing; mapped one-to-one to Latin | Shapes built from proto-glyphs common across real writing systems | https://www.omniglot.com/conscripts/wakandan.htm ; https://www.printmag.com/comics-animation-design/the-typography-of-black-panther/ |
| Kryptonian, Man of Steel | Designed by linguist Christine Schreyer. Abugida: symbol = consonant, orientation = vowel; every symbol has at least one closed cell | The closed-cell orientation rule used in symbology v0 | https://dailyplanetdc.com/2020/09/21/understanding-schreyers-kryptonian-language/ |
| Kryptonian, comics history | Long history of decorative script without a fixed specification | Lesson: script without a spec cannot carry data | https://en.wikipedia.org/wiki/Kryptonian |
| Asgardian (MCU) | Only a fan thread found; no reliable design source | Unusable until a primary source is found | https://www.reddit.com/r/marvelstudios/comments/o6w5do/can_anyone_decipher_this/ |
| Kree | Not researched | Open | n/a |
| DC Atlantean | Not researched. The search returned the Disney *Atlantis* language by Marc Okrand, which is not a DC or Marvel work | Excluded | n/a |

Key finding: the widely seen Wakandan and Kryptonian alphabets are one-to-one substitutions of English, which are weak by construction.
