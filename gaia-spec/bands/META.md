# Meta band — knowledge, skills, powers, magic

Issue: #1363. Listed only. Reading this file grants nothing.

Normal and super shelves already exist. This file adds the missing meta row.
Meta describes the other bands. It is not an actuator and not a second constitution.

| domain | normal | super | meta |
| --- | --- | --- | --- |
| knowledge | `gaia-ukd` | `gaia-aikd` listed tiers | `meta:knowledge` |
| skills | `gaia-skills` | `gaia-aisd` listed; do not score humans on it | `meta:skills` |
| powers | skill capability nodes | `gaia-hspd` declare-only | `meta:powers` |
| magic | wonder labels | `gaia-hmgd` + `gaia-aimd`, `gaia_enabled = false` | `meta:magic` |

Every row has `grants = false`. Prototype: `gaia-cli bands`.
