# International meta matrix

Listed only. Reading this file grants nothing. Not a second constitution. Not a live civic ingest. Not `v1.0.0`.

Magic is mapped so it is not forgotten. It is not a meta shelf and not a consciousness certificate. Chaos and order stay the research anchors: #1175, #1204, #1205, #1176, #1207, #1208.

## So everyone can understand

- Stable ids. English in this file is a display language, not the identity.
- v0 languages remain six BCP-47 tags plus `und`. One thousand languages is vision #651, not this matrix.
- Every cell is `listed`. `grants=false`. `live=false`.
- No tradition is operational. Honor all, privilege none. A tradition absent from `traditions.csv` is not excluded. `und` is the slot for that.
- Sacred text is not copied here. A constraint is a modern limit on the system, not a claim to speak for a faith.
- Local and traditional knowledge is not scraped into the center. TEK stays behind its existing gate.
- Scales are names of work not yet begun: city, county, state, country, continent, global. No registry is queried.
- Invented symbols are refused. A translator should be able to read the csv without the crate.
